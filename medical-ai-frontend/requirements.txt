How to install on the new laptop:

Install Python (v3.10, 3.11, or 3.12 recommended).

Open terminal in backend folder.

Run:

Bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Mac/Linux:
# source venv/bin/activate
pip install -r requirements.txt
2. Frontend Dependencies (frontend/package.json)
You don't need to create this file manually if you copy your package.json, but here is the list of libraries you need to install.

Run this command inside your frontend folder:

Bash
npm install react react-dom react-router-dom axios framer-motion tailwindcss postcss autoprefixer lucide-react recharts react-dropzone react-markdown jwt-decode clsx tailwind-merge
Breakdown of what these do:

Core: react, react-dom, react-router-dom (Navigation).

API: axios (Fetching data from Django).

Styling: tailwindcss, postcss, autoprefixer, clsx, tailwind-merge.

Animations: framer-motion (For your UI transitions).

Icons: lucide-react (The icons used in the dashboard).

Charts: recharts (For the SHAP/Confidence graphs).

Utilities: react-dropzone (File upload), react-markdown (Chatbot responses), jwt-decode (Auth).

3. Setup Checklist for New Laptop
Clone/Copy Code: Copy your project folder to the new laptop.

Environment Variables:

Create a .env file in backend/core/ (or wherever settings.py is).

Add your keys:

Plaintext
GROQ_API_KEY=gsk_...
PINECONE_API_KEY=pcsk_...
HUGGINGFACEHUB_API_TOKEN=hf_...
DJANGO_SECRET_KEY=your_secret_key
DEBUG=True
Backend Setup:

Install requirements (as above).

Run migrations: python manage.py migrate.

Crucial: Copy your ml_models folder (the .pkl and .pth files) to backend/ml_models.

Crucial: Run python ingest_data.py once to setup the RAG database again.

Frontend Setup:

Run npm install.

Run npm run dev (or npm start).
